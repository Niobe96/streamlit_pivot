[안내] KCDW 데이터 분석 어시스턴트 가이드

환영합니다! KCDW 데이터 분석 어시스턴트는 복잡한 코딩이나 통계 지식 없이도 누구나 쉽게 의료 데이터를 정제하고 심도 있게 분석할 수 있도록 돕는 대화형 분석 플랫폼입니다.

본 가이드에서는 처음 사용하시는 분들을 위해 앱 접속부터 최종 결과물 다운로드까지의 전체 흐름을 단계별로 안내합니다.

1단계: 로그인 및 데이터 업로드

▶ 로그인

앱에 처음 접속하면 로그인 화면이 나타납니다. 발급받은 아이디와 비밀번호를 입력하여 로그인합니다.

▶ 데이터 업로드

  1. 화면 왼쪽 사이드바에 있는 [데이터 파일 업로드] 영역을 찾습니다.
  2. 분석하고자 하는 데이터 파일(.csv 또는 .xlsx)을 드래그 앤 드롭하거나 클릭하여 업로드합니다.
  3. 데이터가 성공적으로 업로드되면 자동 분석이 즉시 실행됩니다:
    • - 총 행/열 개수, 수치형/범주형/날짜형 변수 목록
    • - 결측값이 있는 컬럼과 개수
    • - 날짜 형식으로 보이는 컬럼의 자동 변환
    • - 1:N 반복 구조 감지 (예: "환자ID 기준 평균 3.5행 반복")

2단계: 초기 데이터 설정

자동 분석이 끝나면, 본격적인 분석 전에 데이터의 기준을 설정하는 단계가 시작됩니다.

1) 환자 ID 및 종속변수 지정

설정 항목 설명 예시
환자 ID 컬럼 개인을 식별하는 고유 식별자. 설정하면 분석 변수에서 자동 제외됩니다. Patient_ID, 등록번호
종속변수 컬럼 분석의 목표(결과) 변수. 회귀분석 등에서 Y변수로 자동 선택됩니다. 발병여부, 생존일수
  • 종속변수가 수치형이지만 실제로는 범주를 의미하는 경우(예: 0/1 코드), [범주형으로 변환] 체크박스를 활성화하세요.
  • 설정이 끝나면 [다음 단계로] 를 클릭합니다. 나중에 설정하려면 [건너뛰기] 도 가능합니다.

2) 데이터 타입 확인 및 변환

각 컬럼의 데이터 타입을 확인하고 필요 시 변환하는 단계입니다.

  • [추천] 타입 변환: 앱이 데이터를 자동으로 스캔하여 범주형으로 변환하면 유리한 컬럼을 추천합니다.
    • [추천 모두 적용하기]: 추천된 변환을 한번에 일괄 적용
    • 개별 추천 옆의 [변환]: 하나씩 선택적으로 적용
  • 수동 타입 변환: 하단의 데이터 타입 표에서 행을 클릭하여 원하는 타입으로 직접 변경할 수 있습니다.
    • 선택 가능한 타입: 수치형 (float) / 정수형 (int) / 문자형 (object) / 범주형 (category) / 날짜형 (date)
  • 복구하기: 잘못 변환했다면 변환 이력에서 복구 버튼을 눌러 원래 타입으로 되돌릴 수 있습니다.
  • 모든 설정이 끝나면 [설정 완료 - 분석 시작!] 을 클릭합니다.

설정 완료 후에도 사이드바의 [설정 변경] 버튼으로 언제든지 돌아와서 수정할 수 있습니다.

3단계: 데이터 탐색 (기초 분석)

메인 화면에서 [데이터 탐색] 버튼을 클릭하면 9가지 기초 분석 도구를 사용할 수 있습니다.

  • 분포 및 이상치 분석: 수치형 변수의 히스토그램과 박스플롯을 통해 분포와 이상치를 확인합니다. 선택하지 않으면 모든 수치형 컬럼을 분석합니다.
  • 상관관계 (피어슨): 수치형 변수들 간의 피어슨 상관계수 히트맵을 자동 생성합니다.
  • 결측값 및 기술통계 분석: 막대 그래프로 결측값 현황을 보여주고 상세 기술통계(왜도, 첨도)를 요약합니다.
  • 이상치 탐지: IQR(1.5xIQR)과 Z-score(|z|>3) 두 가지 방법으로 이상치를 정밀 탐지합니다.
  • 빈도 분석: 범주형 변수의 빈도수와 비율을 막대 그래프 및 파이 차트로 시각화합니다.
  • 스피어만 상관분석: 순서형 및 비정규 데이터의 비선형 관계를 잡아내는 히트맵입니다.
  • 산점도 행렬: 수치형 변수 모든 조합의 산점도를 행렬 형태로 제공합니다.
  • 다중공선성 확인 (VIF): 분산 팽창 인수(VIF)를 계산합니다. (VIF값이 10 이상이면 변수 제거 권장)
  • 바이올린 플롯: 그룹별 데이터의 분포 형태와 박스플롯을 동시에 시각화합니다.

4단계: 통계 검정 (고급 분석)

메인 화면에서 [통계 검정] 버튼을 클릭하면 11가지 통계 분석 도구를 사용할 수 있습니다.

  • 두 그룹 비교 (T-test): 정규성을 자동 확인하여, 독립 t검정 또는 Mann-Whitney U검정을 자동 수행합니다.
  • 여러 그룹 비교 (ANOVA): 3개 이상 그룹 비교. Tukey 사후검정이 자동 실행됩니다.
  • 영향 분석 (Regression): 선형 회귀분석으로 변수가 목표값에 미치는 영향을 파악합니다.
  • 카이제곱 검정 (Chi-squared Test): 범주형 변수 간의 독립성을 검정합니다. 교차표 포함.
  • 전후 비교 (Paired T-test): 같은 대상의 전/후 수치 비교. 비정규 시 Wilcoxon 부호순위 검정으로 전환.
  • Kruskal-Wallis: ANOVA의 비모수 버전.
  • 비율 비교 (Proportion Test): 두 그룹 간 특정 값의 비율 차이를 검정합니다.
  • 로지스틱 회귀 (Logistic Regression): 이진 결과를 예측하는 분석입니다.
  • 생존분석 (Kaplan-Meier): 시간에 따른 생존 확률 곡선을 그립니다. Log-rank 검정도 지원.
  • Cox 회귀 분석 (Cox Regression): 여러 변수가 생존에 미치는 영향을 분석하는 비례위험 모델 (위험비 HR 도출).

5단계: 데이터 펼치기 (피벗 변환)

메인 화면에서 [데이터 펼치기] 버튼을 클릭하면 2가지 피벗 모드를 사용할 수 있습니다.

▶ 1:N으로 펼치기

한 환자가 여러 행에 걸쳐 반복된 데이터(예: 여러 번의 검사 기록)를 한 행으로 가로 정리합니다.

  • 기준 컬럼: 같은 값끼리 묶을 컬럼 (예: 환자ID)
  • 펼칠 데이터 컬럼: 가로로 펼칠 컬럼들
  • 펼치기 옵션: 정렬 기준, 방향 설정 및 컬럼 순서 인터리브(같은 시점 데이터 나란히 묶기) 지원.

▶ 집계하여 요약

데이터를 sum, mean, count, min, max, first 등의 집계 함수로 요약하는 전통적인 피벗 테이블입니다.

6단계: 결과 확인 및 내보내기

▶ 대화형 결과 확인

KCDW 어시스턴트는 챗봇 형식으로 동작합니다. 버튼을 눌러 분석을 지시할 때마다 화면 하단에 새로운 채팅과 함께 분석 결과(표, 그래프)가 자동 스크롤되어 나타납니다. 지나간 분석 기록은 스크롤을 올려 다시 볼 수 있습니다.

▶ 개별 결과 저장

각 분석 결과 아래에 다음과 같은 다운로드 버튼이 제공됩니다:

  • Excel 다운로드 (.xlsx): 데이터 테이블을 엑셀로 저장
  • CSV 다운로드 (.csv): 다른 프로그램에서 활용하기 위해 저장
  • PNG 이미지 저장 (.png): 차트를 고화질 이미지로 저장 (보고서 및 논문 삽입용)

▶ 전체 결과 일괄 저장

여러 분석을 수행한 후, 사이드바에서 모든 결과를 한번에 내보낼 수 있습니다:

  • 전체 분석 Excel 저장: 모든 분석 결과 테이블을 다중 시트 Excel 파일로 한 번에 저장합니다.
  • 전체 분석 이미지 저장 (ZIP): 모든 차트 이미지를 PNG로 묶어 ZIP 파일로 한 번에 저장합니다.

빠른 분석 기능

데이터 설정 완료 후 사이드바에 빠른 분석 바로가기 버튼들이 나타납니다. 메인 메뉴를 거치지 않고 한 번의 클릭으로 원하는 분석에 바로 진입할 수 있습니다.

  • - 분포 확인
  • - 상관관계
  • - 결측 및 요약
  • - 두 그룹 비교(T-test)
  • - 여러 그룹 비교(ANOVA)
  • - 회귀분석
  • - 데이터 펼치기

유용한 팁

▶ 네비게이션

  • [홈으로 가기]: 언제든 최상위 메뉴(데이터 탐색 / 통계 검정 / 데이터 펼치기)로 돌아갑니다.
  • [다시 설정]: 현재 분석의 파라미터를 다시 선택할 수 있습니다.
  • [설정 변경] (사이드바): 환자 ID, 종속변수, 데이터 타입 설정을 변경합니다.

▶ 종속변수 활용

  • 종속변수를 설정하면 T-test, ANOVA, 회귀분석 등에서 비교 대상/목표 변수가 자동으로 선택되어 매번 찾아 선택할 필요가 없습니다.
  • 종속변수는 분석의 편의를 위한 기본값 설정 용도이며, 실행 시 언제든 다른 컬럼으로 변경할 수 있습니다.

▶ 전체 분석 워크플로우 예시

1. 데이터 업로드 (CSV/Excel)
2. 환자 ID 및 종속변수 설정
3. 데이터 타입 최적화 (추천 적용)
4. 데이터 탐색 -> 분포 확인, 결측값 체크
5. 통계 검정 -> T-test, ANOVA 등 수행
6. 전체 분석 Excel 저장 및 이미지 ZIP 저장

주의사항

  • 새 파일을 업로드하면 이전 분석 기록이 모두 초기화됩니다.
  • 분석 결과는 세션 내에서만 유지되며, 브라우저를 닫거나 새로고침하면 사라집니다. 중요한 결과는 반드시 다운로드해 두세요.
  • 대용량 데이터(수만 행 이상)의 경우 산점도 행렬, 생존분석 등의 처리에 다소 시간이 걸릴 수 있습니다.
